# Контракт обработчика заявок LS Detailing

Формы сайта используют единый адрес обработчика. До его подключения пользователю
не показывается ложное сообщение об успешной отправке: сайт предлагает отправить
подготовленную заявку через WhatsApp.

## Подключение

До загрузки `js/main.js` задайте адрес обработчика:

```html
<script>
  window.LS_FORM_ENDPOINT = "https://api.example.ru/lead";
</script>
```

Альтернативный вариант — добавить в `<head>`:

```html
<meta name="ls-form-endpoint" content="https://api.example.ru/lead">
```

## Запрос

Метод: `POST`
Заголовок: `Content-Type: application/json`

```json
{
  "name": "Имя клиента",
  "phone": "+7 (999) 000-00-00",
  "service": "Полировка кузова",
  "request_type": "Запись",
  "comment": "Марка, модель и удобное время",
  "page_url": "https://ls-detailing.ru/services/polirovka-kuzova.html",
  "page_title": "Полировка кузова — LS Detailing",
  "referrer": "",
  "submitted_at": "2026-07-20T12:00:00.000Z",
  "utm_source": "",
  "utm_medium": "",
  "utm_campaign": "",
  "utm_content": "",
  "utm_term": ""
}
```

Успехом считается любой ответ `2xx`. При ошибке или тайм-ауте сайт делает ещё
одну попытку, после чего показывает резервную ссылку WhatsApp.

## Требования к серверу

- принимать запросы только с `https://ls-detailing.ru`;
- валидировать имя, телефон, тип обращения и допустимую длину полей;
- отклонять заполненное поле `website` как спам;
- ограничивать частоту запросов по IP;
- хранить `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` только в переменных окружения;
- отправлять сообщение через Telegram Bot API;
- сохранять заявку в резервное хранилище до подтверждения доставки;
- не возвращать токен, `chat_id` или внутренние ошибки клиенту.
