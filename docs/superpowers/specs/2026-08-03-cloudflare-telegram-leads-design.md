# Постоянная отправка заявок сайта LS Detailing в Telegram

## Цель

Подключить все формы опубликованного сайта `ls-detailing.ru` к защищённому постоянно доступному обработчику, чтобы каждая успешно отправленная заявка автоматически появлялась в закрытой Telegram-группе. Убрать WhatsApp из сценария отправки форм; ссылки WhatsApp в шапке, подвале и отдельных иконках связи остаются без изменений.

## Согласованный объём

- Публичный сайт продолжает работать на текущем адресе без визуального изменения форм.
- Все формы, которые собирают имя и телефон, используют один публичный HTTPS endpoint.
- Обработчик размещается в Cloudflare Workers Free и разворачивается из GitHub.
- Бот только отправляет уведомления в существующую Telegram-группу.
- Переписка с клиентами, команды бота, статусы заявок, CRM и база заявок в эту временную демонстрацию не входят.
- WhatsApp используется только при осознанном нажатии посетителя на отдельную иконку или ссылку WhatsApp.

## Архитектура

```text
форма на ls-detailing.ru или www.ls-detailing.ru
  → HTTPS POST Cloudflare Worker
  → проверка источника, полей и согласия
  → Telegram Bot API sendMessage
  → закрытая группа «LS Detailing — заявки»
```

Worker получает настройки `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` как зашифрованные секреты Cloudflare. Эти значения не добавляются в HTML, клиентский JavaScript, Git или журнал ответа формы.

## Данные и формат сообщения

Форма передаёт:

- имя;
- телефон;
- тип обращения;
- выбранную услугу;
- комментарий;
- URL страницы;
- UTM-источник при наличии;
- факт согласия на обработку персональных данных.

Worker отправляет в Telegram одно читаемое сообщение с именем, телефоном, типом обращения, услугой, комментарием и страницей-источником. Текст согласия в Telegram не дублируется, но запрос без установленного согласия отклоняется.

## Клиентское поведение

- Перед отправкой форма по-прежнему требует установленную галочку согласия.
- Во время запроса кнопка блокируется, чтобы исключить повторную заявку двойным нажатием.
- При ответе Worker об успехе форма показывает «Заявка отправлена» и очищает введённые данные.
- При сетевой ошибке или ошибке Telegram форма показывает нейтральное сообщение «Не удалось отправить заявку. Попробуйте ещё раз или позвоните нам» и сохраняет введённые поля.
- Тексты «Онлайн-отправка подключается» и «Отправить эту заявку в WhatsApp» удаляются полностью.
- Автоматического открытия WhatsApp после отправки или ошибки нет.

## Валидация и защита

- Worker принимает только `POST` и CORS preflight `OPTIONS`.
- Разрешённые браузерные источники: `https://ls-detailing.ru` и `https://www.ls-detailing.ru`.
- Обязательны непустое имя, допустимый российский номер телефона и значение согласия `true`.
- Длина строк ограничивается до передачи в Telegram, чтобы исключить чрезмерные запросы.
- Ответы API не раскрывают токен, ID группы или текст внутренних ошибок Telegram.
- Токен, ранее переданный в переписке, считается демонстрационным. Для последующей постоянной эксплуатации его нужно перевыпустить через BotFather и заменить только в секрете Cloudflare.

## Обработка ошибок

Worker считает заявку принятой только после успешного ответа Telegram Bot API. Если Telegram недоступен или отклоняет запрос, Worker возвращает ошибку, а клиент не очищает форму. Это исключает ложное сообщение посетителю об успешной отправке. Отдельное резервное хранение не добавляется, потому что для согласованной временной демонстрации источником заявок является Telegram-группа.

## Развёртывание

- Проект Worker хранится в том же GitHub-репозитории в отдельном каталоге.
- Cloudflare подключается к GitHub и автоматически публикует Worker из согласованной ветки.
- Публичный URL Worker добавляется в конфигурацию форм сайта.
- После публикации статического сайта выполняется проверка без кеша и настоящая тестовая отправка.
- Адрес пользовательского сайта и SEO-настройки не меняются.

## Проверки

- Модульные тесты Worker проверяют валидную заявку, отсутствие согласия, неверный телефон, запрещённый Origin и ошибку Telegram.
- Клиентский тест подтверждает единственный запрос, блокировку повторного нажатия, сохранение полей при ошибке и отсутствие WhatsApp-fallback.
- Поиск по отслеживаемым файлам подтверждает отсутствие реального токена Telegram.
- Опубликованный Worker отвечает на проверочный запрос и разрешает запросы только с двух доменов сайта.
- Тестовая заявка с опубликованного `ls-detailing.ru` появляется в существующей Telegram-группе.

## Критерий готовности

Владелец открывает опубликованный сайт, заполняет любую форму, устанавливает согласие и нажимает кнопку один раз. Форма показывает успешную отправку, а в закрытой Telegram-группе появляется одно уведомление с теми же данными. WhatsApp при этом не открывается и не предлагается.
