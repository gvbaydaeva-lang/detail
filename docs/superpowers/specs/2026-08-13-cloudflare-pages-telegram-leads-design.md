# Публикация LS Detailing и доставка заявок в Telegram

## Цель

Перенести публикацию сайта `ls-detailing.ru` с GitHub Pages на Cloudflare Pages и
подключить все формы к существующему Telegram-боту. Заявки должны поступать в
Telegram автоматически. Диалоги с посетителями, CRM, личный кабинет и база
заявок не требуются.

## Согласованный объём

- GitHub остаётся хранилищем исходного кода.
- Cloudflare Pages публикует статический сайт из репозитория GitHub.
- Домен `ls-detailing.ru` и редирект с `www.ls-detailing.ru` сохраняются.
- Одна Cloudflare Pages Function принимает заявки со всех форм.
- Функция отправляет уведомление через существующего Telegram-бота.
- Используются бесплатные тарифы Cloudflare и Telegram.
- Единственный обязательный регулярный внешний платёж — продление домена у
  текущего регистратора.

## Архитектура

```text
GitHub repository
  -> Cloudflare Pages deployment
  -> ls-detailing.ru
  -> POST /api/leads
  -> Cloudflare Pages Function
  -> Telegram Bot API
  -> личный чат или закрытая группа владельца
```

Браузер не получает `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Эти значения
хранятся только как зашифрованные секреты Cloudflare.

## Данные заявки

Форма передаёт:

- имя;
- телефон;
- тип обращения;
- услугу;
- комментарий;
- адрес страницы;
- UTM-метки при наличии;
- подтверждение согласия на обработку персональных данных;
- скрытое honeypot-поле для отсеивания простого спама.

Сообщение Telegram содержит только данные, необходимые сотруднику для связи с
клиентом. Токен, ID чата, IP-адрес и внутренние ошибки в сообщение не включаются.

## Поведение формы

- Без имени, корректного телефона и согласия заявка не отправляется.
- Во время отправки кнопка блокируется от повторного нажатия.
- Успех показывается только после подтверждённого ответа Telegram.
- После успеха поля очищаются.
- При ошибке поля сохраняются, а посетителю предлагается повторить попытку или
  позвонить.
- WhatsApp не открывается автоматически и не используется как часть отправки
  формы. Обычные ссылки WhatsApp на сайте сохраняются.

## Защита

- Функция принимает только `POST /api/leads` и CORS preflight `OPTIONS`.
- Разрешены браузерные запросы только с `https://ls-detailing.ru` и
  `https://www.ls-detailing.ru`.
- Размер и длина полей ограничиваются.
- Заполненное honeypot-поле считается спамом.
- Ошибки API не раскрывают секреты.
- Если токен бота ранее передавался в открытом виде, он перевыпускается через
  BotFather до запуска.
- Отдельное постоянное хранилище заявок не создаётся. При временной ошибке
  Telegram форма показывает ошибку и не очищает введённые данные.

## Публикация и домен

Cloudflare Pages подключается к репозиторию `gvbaydaeva-lang/detail`. Сначала
проверяется preview-развёртывание без изменения DNS. После успешных тестов
домен переключается на Cloudflare. Текущий GitHub Pages остаётся доступным до
момента переключения, поэтому простой сайта сводится к обновлению DNS.

После подтверждения работы production-веткой становится `main`. Новые изменения
из GitHub автоматически публикуются Cloudflare Pages.

## Проверки

- локальные тесты формы и функции;
- отсутствие Telegram-токена в отслеживаемых файлах и опубликованном JavaScript;
- preview-сайт открывается и загружает стили, изображения и скрипты;
- разрешённый CORS preflight проходит, чужой Origin отклоняется;
- тестовая заявка с preview попадает в Telegram;
- основной домен и `www` работают по HTTPS после переключения DNS;
- одна настоящая заявка с `ls-detailing.ru` создаёт ровно одно уведомление;
- при искусственной ошибке форма сохраняет введённые данные.

## Критерий готовности

Посетитель открывает `https://ls-detailing.ru`, заполняет любую форму и нажимает
кнопку один раз. На сайте появляется сообщение об успешной отправке, а владелец
получает одно уведомление в Telegram. Сайт, функция и Telegram работают на
бесплатных тарифах, база данных отсутствует.
